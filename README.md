# STREAKFIT

健身习惯交互原型：今日任务、入门训练、饮食/饮水/睡眠记录、XP、连续打卡和路线。

需要 Node.js >=22，无第三方依赖。

```sh
cd /workspace/workspace-streakfit
npm start
```

默认端口 3000，可用 PORT 覆盖。记录保存在当前浏览器 localStorage。
详细 PRD、页面架构、MVP 范围、技术选型和数据库方案见 [docs/MVP.md](docs/MVP.md)。

这不是已完成的正式健身产品：当前训练是固定模板，教学为文字，没有真实视频、账号、AI 或跨设备同步。

## 第二版原型

补齐经验、器械、饮食和睡眠问卷；按每周频率生成两周路线，自动区分训练和恢复日；按器械选择入门模板。记录每组重量、次数、感受，展示训练容量和个人体重历史，基于历史记录提示保持或增加一次。手机提供底部导航。阶段进阶、完整个性化周期和真实短视频尚未开放；建议由规则生成，不是 AI 或医学处方。

问卷现在提供细分目标、地点联动的多选器械、饮食类型、就餐方式与选填忌口。新增器械仅记录可用条件；未覆盖的课程不自动生成。

## 全身动作库 v0.5.0

32 个动作覆盖 10 个主要肌群，可按肌群和器械筛选。每周 1–3 天全身、4 天上下肢、5–7 天推拉腿搭配轻量活动；按实际器械匹配。短时段轮换附属肌群；长时间预算不代表必须练满。已有训练采用记录时快照。视频仍未接入。

## 可调节排课 v0.6.0

支持固定星期（手选或按频率自动分配）、按开始日期循环训练与休息。提供练3休1、练4休1、练1休1、练1休2与自定义。力量分配可选全身、上下肢和推拉腿，跨周按训练日顺序推进。修改影响未记录的计划，已有训练快照保留。

## 动作替换 v0.8.0

每个动作可替换为相同肌群且可用器械匹配的动作，可选保存为后续计划偏好。新增哑铃卧推（需哑铃及训练凳）。旧组记录按原动作保留在数据追踪，不转移重量到新动作。

## 推拉腿模板 v0.9.0

推拉腿按不同动作模式安排多个动作，结合器械、时长、经验和估算休息时长。充分器械的有经验用户 120 分钟推日可选 3 胸、2 肩、2 三头、1 核心；新手缩减动作数量。页面展示直接组数、动作模式和休息建议。该规则原型尚未经教练审核，不代表个人专业处方。

## v0.28.0：基础体验与每周成长

首次设置收敛为六步：运动前确认、目标、经验、地点、时间、确认。重量单位、年龄、体重和节奏仍可在最后的可选设置或快速编辑中修改。首次默认短时基础课与练一天/休两天节奏。两项运动前确认用于识别明显症状和需要专业指导的情况，不属于已验证的医学筛查或医疗许可；不确定、限制运动或明显症状时可查看/编辑，但暂不开始训练。严重症状提示优先显示。
