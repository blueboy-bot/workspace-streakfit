# STREAKFIT v0.34.3 — 手机体验修订

独立预览版本。正式首页、英文首页和 v0.34.0 / v0.34.1 / v0.34.2 原样保留。

## 五位评审建议落实

- 保存正常身体反馈不会自动解除主动暂停。疼痛、紧急症状与运动前确认仍阻止训练；身体情况更新后必须明确继续。
- 引导卡片恢复可展开的动作说明。明细折叠；完成动作按钮和短休息状态靠近记录区。
- 主动切换动作定位标题；普通记组保持当前位置，并恢复记录按钮焦点、播报真实保存结果。
- 明确选择停练后重新开始时，旧负重只作为参考。新确认记录有时间戳，同一回归阶段不会反复要求确认；旧重量口径仍需核对。
- 实际次数与推荐范围区分；感受默认未记录，CSV同样保留未记录，不伪装成已确认。
- 英文逐步设置、恢复分支、校验和路线说明按完整句翻译。训练参与使用 workouts，不使用 reps。
- 状态/时间调整入口前移到训练主卡旁。课堂筛选前置，今日动作快捷入口；续学直接展开课程，教学返回原来源。
- 初始化空白日不作为实际历史；未填睡眠显示未记录，主动填0保持真实0。没有外部负重的动作不伪装成已测训练容量。
- 身体反馈弹窗有可访问标题；数字占位文字和边框对比加强；月份导航按钮至少44px；墙壁俯卧撑明确双脚离墙距离。

## 验证

46项针对性自动测试通过。32组手机交互组合通过（320/360/390/430px，两个模式、两种色系、中英文）。另外4组新流程，动作卡、逐步设置、恢复续学、设置、备份下载和离线重载检查通过。

实体 iPhone/Safari、屏幕阅读器和真实用户留存未实测。完整排课矩阵耗时较长，本轮停止该额外全量运行，未计为通过；原始输出保留，实际通过结果以验证JSON为准。此版本没有重写训练排课算法。

保留旧数据及备份兼容性，不因更多组、更重负重或体重变化增加XP。旧版HTML、旧预览目录与正式站点均保留。
