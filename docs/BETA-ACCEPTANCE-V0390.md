# STREAKFIT v0.39.0 内测验收

这是内测候选版，不代表已经完成专业或真人验收。除视频外，账号服务、教练复核、真实手机与真实用户验收也必须有实证；未完成项不能打勾。

## 软件验收

- [ ] 旧备份若安全答案缺失或与状态矛盾，保留训练记录并迁移为待确认/紧急状态，不直接放行。两项安全答案均为“没有”才可开始；“有”“不确定”、缺失或与ready状态冲突时阻止训练。
- [ ] 疼痛继续阻止训练；更新反馈不会自动解除用户手动暂停。
- [ ] 从15分钟改60分钟不会自动补量；日历变更不会自动加量；疲劳调整不创造完成或XP。
- [ ] 全部动作的实际记录、重量口径和目标分开保存；同一动作的不同重量组不产生统一加重建议。
- [ ] 新手5屏流程、开始≤2次、有效实际预填记录1次、同日返回1次；第一次实际负重不得虚构。
- [ ] 两个标签页依次修改时，后保存者收到冲突提示，另一页记录不被覆盖；导出本页未保存版本后再刷新。
- [ ] 旧版→新版→刷新→导出→导入，记录与日期目标一致。旧版网址仍可用；本版首次复制旧预览数据，后续独立保存，不回写旧版，两边修改不自动合并。
- [ ] 更新前副本与最近保存副本可从“帮助与恢复”导出；删除恢复副本不删除当前记录。副本在本机，不是云备份。
- [ ] 缓存完整后离线打开；离线保存后上线不重复计分；更新失败不激活不完整缓存。
- [ ] 反馈文件不自动附姓名、账号、训练、照片或身体记录；GitHub公开提交必须主动确认。

本机保存冲突检测不是跨设备同步，也不是数据库事务。严格同时写入仍应避免，内测按单页面编辑。清理网站数据会同时清理本机副本，文件备份必须保管好。

## 教练复核（尚未完成）

建议先核对10个基础动作：椅子深蹲、墙壁俯卧撑、臀桥、徒手髋铰链、哑铃地板卧推、器械推胸、高位下拉、轻哑铃罗马尼亚硬拉、死虫式、支撑哑铃划船。原有foundationTeaching包含设置、动作要点、常见错误、退阶和停止条件；有文字不等于教学或动作已可靠。

使用`docs/beta/training-review.json`逐项填写：审核者姓名及资格、适用人群、器械设置、动作顺序及理由、剂量与休息、常见错误、退阶/进阶条件、停止与转介标准、意见及日期。图示和器械型号逐项核对；不合格动作暂不进入无人指导内测。AI复核不能代签专业意见。

理论参考（不是自动处方或个体医疗意见）：ACSM 2009《Progression Models in Resistance Training for Healthy Adults》https://pubmed.ncbi.nlm.nih.gov/19204579/ ；WHO 2020身体活动指南 https://www.who.int/publications/i/item/9789240015128 。按目标和掌握程度调整，不以年龄标签代替训练经验，不以固定日历阶段要求加量。

本地SQL与模拟账号测试只能证明对应逻辑，不能证明真实验证码已可用。开通供应商、付费、创建域名须由项目所有者完成或明确授权；不要将secret/service_role放在网页或聊天中。

## 真人观察测试（尚未进行）

首轮限成年人、已完成安全确认且有现场指导条件。先5–8人，由新手为主，适量加入有经验者。先观察一节审核过的训练，之后7–14天观察返回使用。不要用连续打卡考核测试者。

每位仅记录自愿匿名编号：是否5秒内理解下一步、设置步骤/真人用时、首次开始点击数、一组记录输入/点击数、暂停返回次数、误操作、退出原因、愿意继续/不愿意的原因。动作质量由现场合格人员判断，不把完成记录当掌握动作的证明。

发现安全拦截可绕过、记录丢失/串号、未经确认自动增加难度时暂停无人指导测试；普通文案或布局问题登记优先级。不要把未运行的验收填成通过。
