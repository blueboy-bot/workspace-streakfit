# v0.15.0：AI 审查反馈处理结果

## 已处理

| 优先级 | 反馈 | 实现与验证 |
|---|---|---|
| 高 | 保存失败静默 | 持续错误提示、重试、原始损坏数据不覆盖、JSON导出 |
| 高 | 历史日期显示空计划 | 过去/今天/未来分开；过去读取history，只读显示实际组 |
| 中 | 旧记录目标缺失导致积分变化 | 迁移并固定旧目标；不随全局目标变化；不猜测原缺失目标 |
| 高 | 单肌群容量过高 | 自动推荐直接组数限额，近期容量缩减；手动目标保留且警示 |
| 高 | 草稿被当作已完成负荷 | 过去草稿排除；未来预测与实际负荷分开，当天依据实际记录 |
| 中 | 主项周期跳跃 | 按专项主项实际完成曝光和未来计划曝光轮换 |
| 中 | 一个手臂动作无法覆盖两侧 | 数量/预算/器械不足时明确提示，可手动补充 |
| 高 | 初始问卷冗长 | 四个基础问题，器械、周期、生活习惯折叠 |
| 高 | 训练页偏编辑器 | 当天简洁执行模式、单动作记录、下一动作、休息计时、随时返回编辑 |
| 中 | 恢复奖励无需说明行为 | 先选择实际恢复安排再记录；旧恢复记录保留 |
| 中 | 饮水目标固定 | 数据页设置个人目标；今天及后续使用新目标，历史独立 |
| 高 | 动作教学仅占位 | 完成HTTPS视频、来源及授权说明接入；未提供素材的动作仍明确为文字教学 |

## 使用方式

- 当天训练：点击“开始训练 · 简洁模式”。记录组后显示建议休息，可结束休息或切换动作。
- 备份恢复：数据追踪 → 训练数据备份。恢复前读取文件并预览日期数，确认后替换，浏览器保留恢复前副本。不要把软件源码备份当作自己的训练数据备份。
- 动作视频：动作课堂 → 接入动作教学视频。填写有使用权限的HTTPS视频直链、来源和使用权限说明。
- 旧的未来手动课程保留，不静默覆盖；如需应用新的自动排课规则，重新应用当天专项。

## 验证

83项定向测试；配置矩阵18,144组，每组四个日期，另有目标差异与10,560个日程检查；56条原有手机/桌面浏览器流程；新增手机与桌面验证首次四项设置、执行模式、计时、历史记录、配额异常、备份导出、无效与有效恢复、饮水目标、恢复选择和视频地址校验。

## 当前限制

容量参数为产品初始规则，不是通用训练上限；直接组数未自动折算复合动作对其他肌群的间接刺激。未接入可穿戴设备、账号或自动跨设备同步。没有真实授权视频素材，播放器接入完成不等于动作视频库完成。旧记录缺失的原始目标无法精确重建。
