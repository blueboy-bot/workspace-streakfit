# STREAKFIT v0.33.0 手机体验修复

实现上一轮五个独立 AI（GPT-6.1 Sol、GPT-6 Astra、GPT-6 Sol、GPT-6 Luna、GPT-5.6 Sol）的手机实测建议。此次修复由主代理完成，没有再组织新的独立审阅。中英文同步；内部动作 ID、公斤存储口径、已有日志和 XP 规则保持兼容。

| 反馈 | 实现与验证 |
| --- | --- |
| 疼痛后仍说继续 | 显示“更新身体情况”；记录保持禁用，未开放绕过安全暂停的入口 |
| 开始前出现醒目暂停 | 编辑页不显示进行中暂停；训练中暂停为次级按钮，主动暂停后继续为主色 |
| 两列输入错位 | 短字段名与底部对齐；重量口径在就近辅助文字中保留 |
| 未知负重默认 0 | 无历史时留空并要求实际输入；已明确记录的 0 辅助重量仍有效 |
| 教学/动作切换丢草稿 | 按账号、日期、单位、字段保存会话内草稿；教学、首页、编辑与动作切换后恢复；不计 XP、不冒充已提交记录 |
| 完成后强调加组 | 目标完成后突出完成动作/训练；额外组作为次级操作，完成目标后不自动重新开始休息 |
| 休息卡臃肿 | 大字仅用于数字，待机 17px；声音、振动、自动休息收进设置，开始休息标明推荐秒数 |
| 术语、教学重复、触控过小 | 引导模式使用余力中文；教学步骤只列一次，移除巨大视频占位；学习/教学入口至少 44px |
| 开始入口与必填焦点 | 明确开始入口统一进入简洁训练；编辑单独处理；未答安全问题定位第一个未答字段；统一“生成我的训练路线” |
| 删除不明确、无撤销 | 移除收进编辑；明确从该日期移出，提供撤销；有记录时确认，日志保留 |
| 恢复重复、数据难找 | 已记录恢复显示修改入口，记录面板收起；周报和最近三天记录靠前，旧历史、成就、备份与身体记录按需展开 |
| 路线今日安排靠后 | 今日安排摘要与开始按钮置于路线顶部，学习阶段说明收起并放到路线后 |

正文继续保持 16px、主要辅助文字 14px、记录数字 20px，按信息重要性调整，不统一缩小字体。

验证：197 项功能回归通过（未重复运行 18,144 个计划组合的矩阵）；最后文字/计时/历史调整后另跑 16 项针对性测试和 6 项引导/翻译检查。真实 UI 点击覆盖 32 种组合：320/360/390/430px × 引导/进阶 × 绿/蓝 × 中/英文。验证草稿往返、首重校验、5 组与额外组、暂停、疼痛阻断、移除撤销和完成入口。另验证默认徒手课完整收尾、恢复记录后的修改、英语 12 项流程、PWA 的 5 个工作流（安装资源、根路径/仓库子路径、离线、更新与缓存隔离、备份恢复）。无页面脚本异常。

旧测试使用固定 2026 年 10 月训练日期，随真实日期推进会变成历史只读。已用显式测试时钟固定为 2026-10-09，恢复可重复的现在/未来语义；生产应用时钟未改。关于未知负重和重量标签的旧断言已按新的语义更新，同时继续验证独立变体历史和哑铃单只口径。

限制：以上是 Chromium 手机视口/触控模拟，未冒充实体 iPhone Safari、VoiceOver、系统键盘或锁屏提醒验证。草稿仅在当前页面会话中保留；已提交日志仍按现有存储保存。注册及验证码配置没有在此次修复中启用。
