# 提前查看与编辑训练

在「我的路线」点击日期，打开该日的周期安排。可调整动作与目标，修改只影响该日期；恢复日默认没有高强度训练项目，可添加轻活动。

未来日期使用单独的 plannedWorkouts，不写实际完成历史。重量/次数和时长记录按钮禁用，不提前获得 XP。选定日期的周期、训练分配、建议组次不会误用当前日期。自定义组次不写全局偏好；未来动作替换的全局记忆勾选禁用。

返回路线后，调整过的日期标为「已调整」。浏览器刷新仍保留。到当天打开训练时，将准备好的计划导入当前训练，不覆盖营养记录或已经进行的训练。

器械全选以当前地点为范围；例如健身房可用全部显示器械，户外仅选户外列表，徒手与设备互斥。清空后按无器械匹配。

测试：未来日期独立周期、组次及替换、刷新恢复、不同日期互不影响、今日 XP 不变、恢复日预览、当日计划导入；真实手机尺寸浏览器验证未来编辑及器械全选/清空。
