日期：2026-10-17（America/Toronto）。基准v0.38.5 / 10c342266d1e7118dc7421c03dcc289d28279777。只增加独立新版路径，保留旧版。

## 问题与改动

1. index.html 原trainDays/restDays的min=1、generatePlan保存校验与JSON导入都拒绝0。现在这两项接受0–7的整数，不能同时为0，空白也不能等同0；中英文提示同步。按星期固定安排的每周1–7天规则不变。
2. app.js 的schedule、trainingOrdinal、cardioPlan、cycleContext中原有Number(value)||3/1会把0变成缺省值；strengthPrescription也单独计算频率。modules/planning.js新增cycleSchedule统一读取并保留0，只对缺失的旧字段用原3/1默认值。无效本机组合返回恢复状态与有限序号；不会除以0。既有训练算法和动作模板不变。
3. modules/backup.js同步校验，0/7和7/0可完整恢复，旧备份兼容；0/0与越界数据拒绝导入。不存在新数据格式迁移，既有日期日志不删。旧版应用本身仍可能拒绝新版0天排期备份，恢复时应使用新版。

涉及文件：app.js、modules/planning.js、modules/backup.js、index.html、modules/locales/en-ui.js；版本与缓存：package.json、sw.js、scripts/build-preview.py；交付：README.md、使用说明.txt、此报告及JSON证据；新增回归test/zero-cycle.test.mjs。全部原测试、测试辅助与指标定义保持原样。
