# Movement illustration review

Inspect images at native resolution and enlarge both hands in every illustrated phase. Check the requested grip, thumb/finger contact, hand-to-wrist-to-forearm continuity, matching attachment, grip spacing and consistent orientation between frames. Inspect the machine facing and force path separately. A broad full-body check does not establish correct grip details.

Reject or withhold an image when the contact or intended grip is ambiguous. Regeneration, file integrity checks and UI tests do not establish anatomical correctness. Do not describe assistant visual review as professional certification.
