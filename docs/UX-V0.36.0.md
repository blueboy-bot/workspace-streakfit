# STREAKFIT v0.36.0 — 视觉说明试点

用户批准实施上一轮建议的第一阶段：计划调整前后对照、真实组数进度格、高位下拉和胸托哑铃划船两帧图解。以v0.35.0为基础创建独立预览，旧版和正式站点保留。

## 计划对照

时间选择保留自由输入并增加15/30/45分钟快捷项。预览展示当前/调整后预计完整时长、动作数量、缩略图、调整后的确切目标及本次省略动作。记录过的动作和其目标、分钟/活动度组保留；未记录目标采用候选推荐。时长明确为完整安排估算，含已记录部分，不承诺剩余实际用时。省略动作不自动补排。

候选对象是对照与应用的单一来源，修复旧流程预览数量不包含保留日志、应用/录入仍沿用不同旧目标的问题。预览不落盘；确认时检查账号、日期、资料、日志与原预览一致，变化则要求重新预览。应用失败回滚原日记录，保留图与输入，允许重试；成功才记录一次调整历史，不修改其他日期。沿用原恢复与XP政策，不自动写入训练组或恢复完成。

## 进度形状

今日卡片及力量录入区显示非交互进度点和实际数量，如已记录2/3组。空心/实心共同区分，点形对读屏隐藏，真实文字保留。超过目标仍允许记录并显示4/3等实际数量；进度点上限10，不按额外训练量奖励XP。心肺继续按真实分钟显示，活动度按组显示。

## 两帧图解

标准正握高位下拉（pulldown）与胸托哑铃划船（chestsupported）展示起始/发力两个关键位置，每帧一个短提示，可放大并切换，Escape返回原触发器。完整步骤、已有视频及要点学习入口保留在可展开区；停止疼痛的短提醒仍可见。其他握距、单侧等变体不套用这两项图解。

图集是原创AI关键位置示意，已目视核对杠在胸前、胸部支撑和姿态连贯性，未获得专业教练/医学审核，不称为完整或认证动作教程。来源与用途在assets/exercises/SOURCES.json。模块、图集纳入离线缓存，单文件版本嵌入。

## 验证

46项相关测试通过，包括候选不变源、预览/应用一致、已记录目标保护、过期候选拒绝、配额失败回滚/重试、疲劳不自动记恢复、实际进度、本地化、安全、历史修改和单位。

16组合320/390px×中英文×两模式×蓝绿，真实点击验证进度、两帧放大/切换、预览只读、输入使候选失效、应用匹配对照、记录保留、超目标记组；无脚本错误或横向溢出。另测保存失败保留对照并重试一次、未来日期不变、心肺与活动度记录、疲劳恢复建议、标准下拉图解、离线新模块和图集。

局限：Chromium手机模拟，未测试实体iPhone/Safari或屏幕阅读器。其余脑暴建议（器械局部图、替换对照、周报美术与阶段路线）仍为后续。此前辅助重量统计、结束动作清除手动休息、课堂成功反馈折叠仍是独立待办。
