# STREAKFIT v0.34.8 — 历史训练编辑

历史日期的动作卡片可点击，进入紧凑编辑弹窗：修改实际重量、次数，补录或删除组。徒手动作保留动作设置；心肺记录分钟；活动度记录组。取消或无效输入不修改原记录。记录原日期、已有时间戳、重量口径、目标及身体反馈保留；旧哑铃记录缺少口径时不猜测单只或总重。

历史修正冻结原已获得 XP（沿用 legacyXP / rewardPolicy，兼容旧代码），补录更多组不增加奖励，不把历史补录记成今天训练。保存前保留本地最近一次历史修改副本，可撤销；刷新后仍可撤销。若该日期之后被其他操作更改，则阻止过期撤销覆盖新记录。全部删除后仍可从数据追踪的上次修改入口恢复。

保护副本或主记录存储失败时不返回成功，不修改磁盘原记录，保留输入供重试；失败的下一次修改保留之前成功修改的撤销副本。副本属于当前本地工作区，仅保留最近一次历史修改，不是云端历史版本服务。

中英文同步。保留 v0.34.7 及全部旧预览和正式站点，保留两项默认录入与三行休息控制。本次不更改计划生成或未来训练权限。

验证：34 项相关单元测试全部通过；8 个手机视口组合（320/390px、中英文、kg/lb）验证真实 UI 的点击、取消、错误输入、保存、补录/删除、XP、日期、刷新撤销；另测存储失败和重试、过期撤销、离线、徒手/心肺/活动度及旧哑铃口径。最终两语言 390px 回归通过。测试为 Chromium 手机模拟，不是实体 iPhone/Safari、屏幕阅读器或真实用户研究。

未包含此前排课缩短目标不一致、辅助重量统计、手动休息被结束动作清除和课程成功反馈折叠问题。
