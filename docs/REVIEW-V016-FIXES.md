# v0.16.0：独立受众审查修复

本轮依据 v0.15.3 的四角色独立 AI 审查，修复程序与交互问题；不把 AI 审查当成真人用户访谈或专业训练认证。

## 排课

- 全身课程按训练日序号轮换推、膝主导、拉、髋铰链的优先级。短时课从当日优先模式开始，连续多课补齐基础模式；同肌群的主项与辅助仍连续排列。
- 模板与短时候补入口统一经验适配；用户记住的替代动作仍有效。
- 重新开始训练者先使用回归适应：主项 3×6–8、较充分余力与120秒休息。近42天内至少6次完成课程后进入一般周期；不把一次部分记录或久远历史当成完成适应。旧记录没有课程快照时，以至少3个实际工作组为保守近似，不能精确判断训练质量。
- 健康/习惯课先确定最多30分钟的课程预算，再在该预算内分配有氧与力量。增加可用时间不再反向减少力量动作；无需填满两小时。
- 有可用负重/引体/弹力带背部训练时，徒手W提拉不占专项默认工作容量；优先垂直拉、水平拉及负重辅助。器材不足时仍可作为轻量控制练习。
- 肩部A/B日统一考虑近7天胸部推举负荷；达到默认阈值时不再自动追加肩推。
- 容量耗尽的空课明确建议恢复或换部位，显示真实原因；不会自动奖励完成恢复。
- 死虫、鸟狗、W提拉、靠墙滑臂按控制质量与每侧次数指导，不套用接近力竭的RIR。
- 当天部位/动作数量选择提供未保存预览：实际可安排动作数、组数、估计时长及容量限制；点击应用才保存。
- 心肺提供跑步机、骑行、椭圆机、划船、快走、原地踏步选择；默认时长考虑经验与每周频率。同方式实际轻松完成才允许在预算内小幅增加，未完成/较吃力时保持或缩短；不因日历周自动加量。

## 使用体验

- 首页按实际动作目标汇总力量工作组；活动度显示按组和每侧剂量，心肺显示按分钟。
- 恢复首页只介绍恢复安排，另设可选训练编辑入口；恢复任务需要明确选择实际活动。
- 首次设置显示默认训练星期和当天状态，提供“从今天开始·练一天休一天”，高级日程仍可改。
- 当天偏好、周期、容量与器材说明折叠。上方保留“＋添加动作”展开入口；简洁模式继续只显示当前动作。
- 不同页面导航滚回顶部，同页记录不主动滚动。
- 首次选重补充轻重量试做、热身与工作组区别、器械空载/杠铃本身重量计入说明。
- 视频素材网址/授权管理移至数据追踪，不再出现在普通动作教学页。教学保留具体文字步骤；真实授权视频素材仍未提供。

- 81组目标×时间×经验×器材配置逐次记录实际工作组，检查连续两周推、拉、蹲、髋铰链覆盖。
- 配置矩阵18,144组，每组4个日期及训练页面；另有10,560条日程组合检查，通过。
- 原有56条手机/桌面流程通过，含记录、重载、问卷更新与目标输入校验。
- 保存失败、备份导出/恢复、历史记录、计时等浏览器回归通过。
- 新增390px手机和1366px桌面检查首次日程快捷选择、首页实际组数、折叠添加、当天预览、导航回顶、恢复、心肺方式、教学入口；手机首动作位置约826px，桌面约776px。

## 版本使用与边界

已有真实记录、手动目标和未来课程不会批量覆盖。未保存的自动课程采用新规则；已保存的未来课程可在日期页点击重新生成，当天可重新应用偏好。容量、回归门槛和心肺周预算是可调整的产品初始规则，不是面向所有人的权威统一处方。仍未自动折算复合动作全部间接刺激，也没有伤病筛查、账号同步或专业教练审查。没有真实视频素材，不能声称视频库已经完成。
