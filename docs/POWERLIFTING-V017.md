# v0.17.0：力量举相关训练与辅助

力量与增肌共享一些基础动作，但自动力量课现在使用独立的动作槽位和训练角色，而不只是换次数。规则为产品初始方案，未作为职业选手原版训练表或统一权威处方。

## 新增动作

| 动作 | 目的 | 自动安排条件 |
|---|---|---|
| 暂停卧推 | 底部控制与起推 | 有规律经验，杠铃、训练凳、保护架 |
| 节奏卧推 | 下放控制与杠铃路径 | 同上 |
| 暂停深蹲 | 底部稳定与起身 | 有规律经验，杠铃、保护架 |
| 节奏深蹲 | 下蹲控制与姿势稳定 | 同上 |
| 离地暂停硬拉 | 离地位置与躯干稳定 | 有规律经验，杠铃、硬拉台 |
| 绳索 Pallof 抗旋转推 | 抵抗躯干旋转 | 绳索器械 |
| 弹力带 Pallof 抗旋转推 | 抵抗躯干旋转 | 弹力带及可靠锚点 |
| 哑铃分腿蹲 | 单侧腿部力量与稳定 | 哑铃 |

## 排课角色

- 主项：保持可练习的基础动作，按现有重课/训练量/技术轻练周期调整；例如有规律用户重课4×4–6，180秒休息。
- 技术变式：一课最多一种暂停/节奏变式，默认3×3–5、保留约3次余力、150秒休息。用轻于常规主项的负重开始。负重历史独立，不复制主项重量。
- 相关辅助：默认3组，复合辅助通常6–10次，孤立辅助8–12次，约90秒休息；例如胸托划船、罗马尼亚硬拉、腿弯举、三头辅助。
- 核心稳定：按每侧次数、呼吸和控制质量，不用接近力竭的RIR指导。哑铃分腿蹲和Pallof显示每侧次数，完成两侧后记录一组。

一般力量计划保留用户全身/上下肢/推拉腿分配；第一项相关技术变式会加入实际候选，而非只放入动作库。力量目标的胸、股四头、腿后侧专项也使用对应变式。一种变式之后仍需服从时间和容量，不能为了增加动作数堆叠多个重主项。

## 三大项专项

- 卧推日：卧推 → 暂停/节奏卧推 → 胸部相关辅助 → 三头/上背 → 核心稳定。数量有限时核心优先于额外肩后侧动作。
- 深蹲日：深蹲 → 暂停/节奏深蹲 → 单腿稳定 → 膝伸/后侧链 → 核心；直接组数超出默认容量时缩减。
- 硬拉日：硬拉 → 离地暂停硬拉 → 腿弯举 → 臀部辅助 → 上背 → 核心；已有暂停变式时不默认再叠加第三个髋铰链动作。

新手和回归者不自动获得高级杠铃暂停变式；仍先使用基础适应方案。增肌自动计划不加入这些高级技术变式，继续以肌群训练量与常规复合/孤立动作为重点。新增动作仍可在上方添加入口按肌群查找，手动目标优先保留。

## 使用

选择“提升力量”；有规律经验并具备对应器材时生成新的课程。健身房默认器材不包含硬拉台，请按实际条件勾选。当天展开训练偏好可选卧推日/深蹲日/硬拉日。旧未来课程保持原安排，可重新生成；当天可重新应用训练偏好。已有真实训练记录不重写。
