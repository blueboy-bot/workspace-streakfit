# STREAKFIT v0.38.8 检查报告

2026-10-17（America/Toronto）。基准v0.38.7，来源4f711eae162a43c79e7a9f99c1009db0f173ca2f。保留旧版，另存发布，中英文同步。

## 本轮三项问题与最小修改

1. app.js dailyAdjustmentPanel 原预览/确认入口只有普通白字按钮，不易识别下一步。现两个阶段分别突出“预览调整”“应用到今天”，高约61px、整行可点击，预览成功才显示应用；重新预览降为次要按钮。没有自动应用。
2. app.js adjustmentComparison 默认重复展开大量动作、缩略图和长说明。现摘要保留时长、数量、两张缩略图及+N、关键调整原因；动作变化/省略/记录保留细节和设备说明折叠。“仅今天生效，记录保留”始终可见。安全筛查和疼痛提示未削弱。
3. visual.css 中原固定 .plan-start-area 会在手机选择框失焦后重新覆盖预览。现仅当今日调整展开时回到正常文档布局；成功应用回到页首计划并给出状态提示。失败不离开表单，原计划保留可重试。
