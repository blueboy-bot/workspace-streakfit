# 后续原生与云同步接入

v0.30网站提供PWA安装与应用外壳离线使用；单HTML文件可离线打开，但不提供PWA安装。核心文字教学包含在外壳中，远程视频不预缓存。需要HTTPS或localhost，首次在线加载且缓存安装成功后才能离线使用。网页提醒仅在页面运行时检查，不保证锁屏/后台准时触发。

## 原生工程

建议先用Capacitor封装现有网页，使用本地通知插件调度休息结束和每日提醒；安排前征得通知权限，取消/延长计时同步更新原生调度。iOS需要Xcode、开发者签名和真机验证。Apple Health需要独立授权与HealthKit能力，只写入实际完成的运动；Apple Watch需要单独watchOS工程及手机/手表通信，不由Capacitor自动获得。

原生工程启动前把照片及大型历史迁移到IndexedDB，保留迁移备份和失败回退，JSON中继续导出完整数据。应完成真机前台/后台/锁屏、音频静音模式、通知拒绝、时区变化、数据升级测试。

## 云同步

v0.31.0已完成Supabase账号与文档同步代码，数据库、注册函数与Hook已部署，发码服务待配置，前端尚未启用；配置与验证步骤见 [账号接入说明](SUPABASE-ACCOUNTS.md)。正式网站仍无账号或云同步。后续可增加对象存储。日志使用唯一ID与修改时间；离线变更入队，冲突保留双方版本并让用户选择，不按设备最后写入盲目覆盖。照片独立存储且默认不上传；账号和照片均提供删除入口。接入前确定服务地区、隐私政策、保留期限、加密与授权策略并验证RLS、导出和删除流程。

通知、HealthKit、手表、云同步尚未实现，不能以PWA或本地备份替代这些能力。
