## 已修复

1. 除心肺外目标共用方案：现在分成习惯短课、减脂混合、增肌、力量、心肺、活动度、健康混合。
2. 力量与增肌剂量雷同：力量主项偏低次数、更长休息；经验不足先采用较温和次数。增肌保留 4 组 × 8–12 次。
3. 新手长时段可产生过多训练：按经验和时间预算限制推荐，不用动作数量填满时间。
4. 训练目标可能受当前设置影响历史完成判定：记录时保存动作目标和时长快照。
5. 日期仅检查字符串格式：加入真实日历日期验证。
6. 活动度沿用力量或有氧说明：专门活动度动作与按分钟记录；不显示重量组次或中等有氧强度建议。
7. 路线阶段文案：心肺、活动度、习惯、健康不再统一使用增肌阶段名称。

## 当前目标策略

| 目标 | 默认策略 |
|---|---|
| 建立运动习惯 | 最多 3 个基础动作、2 组、8–10 次、较短课程 |
| 减脂与体重管理 | 力量 3 组、10–15 次，时间足够时组合中等有氧 |
| 增肌与体型塑造 | 4 组、8–12 次，按器械和训练分配选动作 |
| 提升力量 | 4 组，熟练者 4–6 次，其他经验 6–8 次，更充分休息 |
| 提升心肺与耐力 | 热身、稳态有氧、放松；按分钟和感受记录 |
| 灵活性与日常活动能力 | 胸椎、髋、踝活动度；按分钟记录，无痛范围 |
| 保持健康与精力 | 少量基础力量 2 组、8–12 次，加轻松有氧 |

手动自定义的目标优先于推荐；旧训练记录仍按保存的目标显示。
