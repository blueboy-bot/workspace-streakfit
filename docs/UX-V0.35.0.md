# STREAKFIT v0.35.0 — 图解今日计划

用户批准按演示图改版，并要求不删除原版本。以 v0.34.8 为基础新增独立预览。正式站点及所有旧预览保留。

## 页面

今日训练使用单列图解卡片：真实动作名、目标组次、实际已记组数/分钟，当前动作细边框突出。只有达到该动作目标时才显示完成勾选。超过目标仍显示真实数量，旧记录入口与录入规则不变。图解是 HTML 文字、真实按钮与装饰插图，图片失败不影响文字和操作。

主按钮随记录显示开始/继续/查看记录。继续入口优先恢复该工作区当天未完成的动作位置，不计 XP，不写入训练日志；移除或已完成的位置回退到当前第一个未完成动作。动作位置可跨刷新保留。已有未提交输入在本次访问中继续由原日期/动作/单位草稿机制保留，不声称刷新后仍保留未提交输入。

卡片打开原动作课堂，返回今日。查看或调整进入原训练编辑器；时间或状态变化打开原预览确认流程。每周、学习、饮食与恢复表单收进可展开区域，保留原功能。恢复日与疼痛/安全暂停继续使用原界面和保护。新开始入口同样经过一天一次的简短提示，明确继续可恢复用户暂停，不能恢复疼痛保护。

到达今天的提前编辑计划先通过既有 workoutDay() 合并再展示，确保卡片和录入目标一致。预计时长根据实际显示目标、休息与转换预算估算，标注“约”，不是个人完成时间预测或要求练满。

## 插图

三张原创 AI 图集，固定格位用于缩略图；具体映射见 modules/daily-overview.js。未配图的握法、器械变体不继承错误图片，回退到标有“部位示意”的中立人体图。图集只用于动作识别，不是运动轨迹教学或已经专业认证的解剖标准；动作教学继续使用原文字和已接入素材。生成来源与排除格位见 assets/exercises/SOURCES.json。

中英文、原有浅绿/深绿/浅蓝/深蓝主题兼容。所有图集和新模块纳入离线缓存，单文件版本嵌入图集。

## 验证

18项相关测试通过，覆盖真实组数/分钟/活动度、继续位置回退、提前计划到期、录入不封顶、历史编辑和单位、本地化。16组合320/390px×中英文×两模式×蓝绿，通过真实点击检查卡片教学、返回、进度、继续、输入草稿和刷新动作位置；无横向溢出或脚本错误。补测首次提示、暂停恢复、昨日疼痛、恢复日、空计划、心肺与活动度、图片失败、生活表单、离线。最后新增图集与标题细化后复测中英文390px及离线资源。
