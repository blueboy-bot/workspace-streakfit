# STREAKFIT v0.34.5 — 两项快速记录

独立预览，保留正式站点和所有旧版本。

- 默认记录区只显示重量（随设置为kg或lb）和次数，两个等宽水平输入框；下方保留记录一组主按钮。
- 感受选择放在记录按钮后的「感受（可选）」展开项，默认收起、值为未记录。不填写也能记录；每次成功保存后不自动沿用上一组感受。未提交的主动选择在教学返回、切动作后保留且展开，避免隐藏已选择状态。
- 单只哑铃、杠铃/器械含空载口径在开始前提醒，字段的无障碍名称与动作说明仍保留原重量口径。辅助引体仍明确显示辅助重量及辅助方向。徒手/弹力带继续使用动作版本或规格，不伪装成kg输入。
- 缩短重量、次数与占位文案，中英文同步；可选项至少44px点击高度。没有修改排课、XP规则或旧记录。

验证：7项现有记录/本地化测试通过；12组合（320、390、1280px×中英文×kg/lb）验证两列对齐、等宽、默认无第三框、无需感受可记录、主动感受只记当组、教学返回与暂停保护、编辑视图保持简洁。另检查徒手版本不显示重量并可记录。不是实体iPhone、Safari或真实用户研究。上一轮五AI审查的排课/统计等其他待办仍未实施。
