# STREAKFIT v0.30.4

当前工作目录打包的最新交互原型。

## 下载与使用

- [下载转发包 ZIP](STREAKFIT-v0.30.4.zip)：打开文件后点击下载图标或 Raw，保存到电脑，解压后用 Chrome、Edge 或 Safari 打开 HTML。
- [单文件 HTML](STREAKFIT-v0.30.4.html)：打开文件后点击 Raw 或下载图标，保存后用浏览器打开；GitHub 文件页显示源代码，不能直接运行应用。
- [网站源文件包](STREAKFIT-v0.30.4-website.zip)：包含当前应用页面、样式、JS 模块、图标、PWA 文件和本地服务器。解压后执行 npm start。

数据保存在当前浏览器。换设备前请在应用中导出完整 JSON 备份；发送此软件文件不会包含你的训练记录。手机文件预览器可能不执行交互脚本，建议电脑浏览器打开或部署网站。离线安装及通知等功能需要支持的浏览器和运行环境。
